## Running Tests

### Method 1: Using Shell Script (Recommended)
```bash
./run-tests.sh
```

### Method 2: Manual Compilation and Execution
```bash
# 1. Compile source code
mkdir -p build/classes
javac -d build/classes -cp "lib/*" $(find src -name "*.java")

# 2. Compile test code
mkdir -p build/test-classes
javac -d build/test-classes -cp "lib/*:build/classes" $(find test -name "*.java")

# 3. Run tests
java -cp "build/test-classes:build/classes:lib/*" com.hospital.TestRunner
```

### Method 3: Run Individual Test Class
```bash
java -cp "build/test-classes:build/classes:lib/*" org.junit.runner.JUnitCore com.hospital.model.UserTest
```

## Adding New Tests

To add new test classes:

1. Create test class in appropriate package under `test/`
2. Extend the test with `@Test` annotations
3. Add the test class to `AllTests.java` suite
4. Run `./run-tests.sh` to execute

Example:
```java
package com.hospital.model;

import org.junit.Test;
import org.junit.Before;
import static org.junit.Assert.*;

public class MyNewTest {
    @Before
    public void setUp() {
        // Setup code
    }

    @Test
    public void testSomething() {
        assertEquals("Expected", "Actual");
    }
}
```

## Troubleshooting

### "JUnit not found"
Download JUnit libraries to lib/ directory or run `./run-tests.sh` which auto-downloads them.

### "Compilation failed"
Ensure source code compiles first:
```bash
./compile.sh
```

### "Class not found"
Check classpath includes both build/classes and build/test-classes:
```bash
java -cp "build/test-classes:build/classes:lib/*" ...
```
